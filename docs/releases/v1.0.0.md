An open driver for the 320x1480 LCD panel in the **Solarmax CM-B600L** case
(`HL-VMAX-USB-Device`, VID_33C3 / PID_F101), replacing the vendor's *LCD Control*.

It installs as a tray app: an icon next to the clock, a right-click menu, and a window for
editing what the panel shows. The panel starts drawing at logon and needs nothing else.

## Installing

Download **Source code (zip)** below. **Unblock it before extracting** — right-click the zip,
Properties, tick **Unblock**, OK — then right-click `install.cmd` and choose **Run as
administrator**.

The installer finds Python, installs the three dependencies, checks the hardware, renders a test
frame you can look at, and asks before registering the logon task. Full instructions in
[docs/install.md](../install.md).

Windows 10 or 11, Python 3.11 or newer.

## What it does

- **Four layouts out of the box** — Apex, Apex (castellano), Embers and Vitals.
- **Layouts are data.** One JSON file per profile, reloaded the moment it is saved. A broken
  file does not blank the panel: the previous layout stays up and the error is reported.
- **A visual editor** with a working preview — drag widgets into place, Ctrl+wheel to zoom,
  a grid to line things up, and colour rules that change a value's colour by threshold.
- **Sensors** for CPU, GPU, RAM, disks, network, fans, temperatures and voltages, from WMI, PDH,
  Gigabyte's GSA1 ACPI-WMI interface and — optionally — LibreHardwareMonitor.
- **Backgrounds**: solid, gradient, image, procedural, image sequence and video.
- **Export and import**: a profile and its assets travel as one `.vmaxpanel` file.
- **Nothing about the hardware is hardcoded.** The COM port is found by VID/PID and the panel
  geometry is parsed from its serial number, so it works with any case carrying the same panel.

## On kernel drivers

The readings from WMI, PDH and GSA1 need no kernel driver at all. The optional
LibreHardwareMonitor DLL does need one: **use 0.9.5 or newer**, where that is PawnIO — signed,
running verified modules — rather than WinRing0, which is on Microsoft's vulnerable-driver
blocklist.

`python -m vmaxpanel --diagnose` reports which one your DLL uses, names its version, and lists
any such driver loaded right now. See [SECURITY.md](../../SECURITY.md).

## Known limits

- Windows only, by design: WMI, PDH, a Windows serial port and Win32 for the tray.
- CPU and VRM temperature and VCore come from Gigabyte's GSA1 interface. On another vendor's
  board those three are blank; everything else is vendor-neutral.
- Apex assumes three volumes, three disks, six cores and an Ethernet adapter. On a smaller
  machine part of it reads `--`. Run `--diagnose` against a profile to see exactly which
  readings it cannot serve, or start from Embers, which reads nothing device-specific.
- Video backgrounds need `ffmpeg` on PATH. Without it the background degrades to a flat colour
  and says so.

639 tests, no hardware required, run against Python 3.11 and 3.13.
